# 🛍️ Sales Store Analytics Dashboard
An interactive Excel Dashboard designed to analyze retail performance across multiple e-commerce channels. This project transforms raw transaction data into actionable insights regarding customer demographics, regional sales, and order fulfillment.

# 📊 Key Features & Visuals
Demographic Insights: Analysis of orders by age group (Adult, Senior, Teenager) and gender.

Channel Performance: Tracks contribution from major platforms including Amazon, Flipkart, Myntra, Ajio, and Nalli.

Geographical Analysis: A "Top 10 States" bar chart identifying high-demand regions like Maharashtra and Karnataka.

Order Logistics: Pie chart visualization of Order Status (Delivered, Cancelled, Refunded, Returned).

Sales vs. Revenue: Comparison of order volume against total sales amount.

Interactive Slicers: Dynamic filtering by Month, Order Status, Category (Kurta, Western Dress, etc.), Channel, and Gender.

# 🛠️ Tech Stack
Tool: Microsoft Excel

Features: Pivot Tables, Pivot Charts, Power Query for data cleaning, and Interactive Slicers.

# 📈 Business Insights
Customer Profile: Identifies that women in the "Adult" category represent a significant portion of the customer base.

Regional Focus: Highlights the top 10 states to help optimize localized marketing and logistics.

Channel Strategy: Visualizes which e-commerce platform yields the highest order volume.

# 🚀 How to Use
Download the .xlsx file from the repository.

Open the file in Microsoft Excel.

Use the Slicer Panels at the top to filter data by specific months or product categories.

All charts will update automatically based on your selections.
